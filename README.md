# My Agent Skills

A collection of reusable skills for AI coding agents. Install skills from this repository with:

```bash
npx skills add YASHxK1/my-skills
```

To install one skill:

```bash
npx skills add YASHxK1/my-skills --skill colab-cli-operator
npx skills add YASHxK1/my-skills --skill colab-ssh-operator
npx skills add YASHxK1/my-skills --skill vibe-coding-planner
```

## Skills

- **colab-cli-operator** — operate Google Colab remote runtimes using the official CLI.
- **colab-ssh-operator** — connect to Colab runtimes through its SSH-over-WebSocket feature.
- **vibe-coding-planner** — create and maintain a structured build plan for AI-assisted coding.
